# Spec — building the new `dop` (28/09)

**Authority for behaviour:** `business-rules.md` (B1–B30). This file only fixes structure, contracts
and the split. Python ≥ 3.11, standard library only; `kubectl`, `docker`, `git` are shelled out.
Comments and identifiers in English.

## Structure

```
pyproject.toml                  package `dop`, console script `dop`
src/dop/
  cli.py                        argparse generated from the verb registry; the one exit-code point
  config.py                     schema + strict loader (B6 §6, unknown/missing key → exit 2)
  outcome.py                    Unit, UnitResult(done|skipped|failed, reason), RunSummary, exit code (B13/B14)
  scope.py                      filters, demand discovery (B11, B26), worktrees (B8, B28), apps (B9, B19), units
  kube.py                       every kubectl call; always --context (B25); dry-run prints, never runs
  node.py                       docker cp staging + in-place content sync inside the node (B6, B24)
  lock.py                       per-unit lock files (B27)
  render.py                     per-demand kustomize overlay (namespace, labels, hosts, hostPaths, urls, scheduler env, secret)
  verbs/<verb>.py               one module per verb; each exports VERB (dimensions, entering?) and run(ctx) -> RunSummary
tests/                          unit tests with fake kubectl/docker/git on PATH
```

**Config location:** `<workspace>/dop.toml`; the workspace is `--workspace PATH` or the nearest
ancestor of the working directory holding a `dop.toml`. (This locates the *workspace*, never a
demand — B7 stands.)

**Contracts fixed in step 1** (the verbs consume them, so they exist before any verb):
`Context(ws, filters, dry_run, out)`, `address(ws, demand, app, form="browser"|"service")`,
`expand(template, ws, demand)` (renders `{url:<app>}`), `Runner.run(image, mounts, env, network, workdir)`
(host containers, dry-run aware), `resolve(ctx, verb) -> Scope(units, skipped)`, `Kube.run(args)`,
`Node.sync(src_dir_on_host, dest_dir_in_node)`, `lock(unit)`, `render_demand(ws, demand, apps) -> dir`,
the verb registry, and the `dop.toml` schema below.

```toml
[cluster]      context = "k3d-dop-local"; node = "k3d-dop-local-server-0"; node_root = "/workspace"
[address]      domain = "localhost"; port = 8080; namespace_prefix = "optum"; shared_namespace = "optum-shared"
[paths]        manifests = "k8s"; env_file = "docker/.env"; reports = "test/e2e/reports"; test_root = "test"
[repos.<name>] dir = "repos/<name>"
[apps.<name>]  repo; kind = "backend"|"frontend"; service; port; artifact = "target"|"dist"
               build = { image, command, env = { VAR = "{url:<app>}" } }; forbidden = ["localhost:8090"]
               calls = [{ app, key, fallback }]; companions = ["<app>"]; scheduler_off = { KEY = "false" }
               secrets = ["ENV_KEY"]; suite = "<dir under test/e2e>"; suite_env = { VAR = "{url:<app>}" }
[runners]      maven = "<image>"; e2e = "<image>"; allure = "<image>"
```

**Render patch targets, by name** (step 3 conforms the base to these): Ingress `<app>` (host);
Deployment `<app>` volume named `artifact` (hostPath → `/workspace/<ns>/<app>`); ConfigMap
`optum-urls` (B18 keys); ConfigMap `optum-env` (B20 scheduler env); Secret `optum-app-secrets`
generated by render from B30 (the base's placeholder Secret is removed); Namespace labels (B26).

## Split

Every builder works in `/opt/wks/dbo/dop/repos/dop-cmd/.worktrees/k3s` (branch `k3s`), absolute
paths, no git writes.

1. **Core** — builder, senior, high. Everything under "Structure" except `verbs/*` bodies; the verb
   registry with stub verbs that resolve scope and return skipped units; tests for B7, B8, B11–B16,
   B25–B28, config strictness. *Before anything else.*
2. **Verbs** — three builders in parallel after 1, each owning only its `verbs/` modules and their
   tests:
   - 2a `env up`, `up`, `down`, `status`, `log` (B4, B10, B18–B20, B26, B30) — mid, high
   - 2b `build`, `deploy` (B17, B24, B6) — mid, high
   - 2c `test aaa|it|e2e`, `report` (B21–B23, B29) — mid, high
3. **Workspace** — builder, mid, high, parallel with 2: `/opt/wks/csptech/optum/dop.toml` for the
   nine apps (including, per suite, every URL key the suite's sources read — B33); `k8s/` conformed
   to the patch targets above; shared `reports` nginx serving the node's reports dir at
   `reports.<domain>`; removal of `demand/e2e-runner`, `demand/aaa-runner`, novnc, their policies,
   `shared/allure` (B21/B23 make them dead); README's "no restart" line fixed.
3b. **Records** — builder, mid, medium, after 2 and 3, before 4: ADR-03 and ADR-05 of the workspace
   rewritten for the new `dop` (verbs, addresses, headless-only e2e, reports).
4. **QA** — qa-lead at the architect's seniority, judging only against `business-rules.md`.
5. **End to end** — the architect runs one real demand: `env up → up → build → deploy → test e2e →
   report → down`. **Pass today** = the demand's apps are reachable at their own hostnames through
   the one port and the e2e run reaches them; an authentication failure for lack of e2e credentials
   (none exist in `docker/.env`; the human supplies them) is recorded, not a fail of the tool.
